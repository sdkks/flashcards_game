How to Load Cards by Link

You can load flashcard data into the app by providing a URL to a CSV file. This guide shows you how to prepare and host your CSV.

CSV Format

Your file must have a header row followed by one row per card. Each row has two fields: the question and the answer.

question,answer
apple,epal
door,pintu
twelve,dua belas

Choosing a Separator

By default the app uses a comma (,) as the delimiter. If your questions or answers contain commas or special characters, switch to the pipe separator (|) in Settings before fetching:

question|answer
What is 2+3?|5
red, white, blue|the colours of the flag
café|coffee shop

Supported separators: , (comma), | (pipe), Tab, ; (semicolon), : (colon).

Make sure the separator you choose in Settings matches the one used in your CSV file.

Option 1: GitHub Gist (recommended)

  1. Go to gist.github.com and sign in.
  2. Name your file something like my-flashcards.csv.
  3. Paste your CSV content and click Create public gist.
  4. Click the Raw button on the file and copy the URL.
  5. Paste the raw URL into the Add by Link field in the app, or use it as a deeplink: ?cards=RAW_URL.
  6. Then you can also autoload with a deeplink such as: Flashcards from Github Gist Raw Data

Option 2: Export from a Spreadsheet

  1. Create your flashcard pairs in any spreadsheet app (column A = question, column B = answer).
  2. Export or download as CSV (File > Download > Comma-separated values).
  3. You can load the downloaded CSV in two ways:
    • Upload directly — Open Settings (cog icon) > Upload CSV and select the file. This is the quickest option for personal use.
    • Share via link — Upload the CSV to a public host (e.g., a GitHub Gist) and use the URL in Add by Link or as a deeplink (?cards=URL). This lets you share the deck with others.
