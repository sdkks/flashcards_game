# Roadmap

## Under consideration

### Configurable mixed-deck trivia

Consider a separate, opt-in game type that draws questions from multiple selected decks or categories, with configurable mixing behavior.

Regular study and quiz sessions, including sessions started from **I'm feeling lucky**, remain single-deck: Lucky selects one eligible deck, and every question in that session comes from it.

Mixed-deck play is not part of the current trivia expansion.
